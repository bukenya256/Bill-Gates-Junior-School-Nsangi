# BGS 1.4 update

- Teacher PC requires its own local password at first launch; passwords cannot be recovered from cloud.
- Headteacher can configure class subjects and grade thresholds. Changes sync to teachers via LAN. Grading changes apply to historical report calculations too.
- Notification Centre saves local and cloud-backed drafts; sending is deliberately disabled until SMS API integration is installed.
- Icons updated and EXE/DMG artwork added.
- Do not place SMS or other API keys in GitHub.
- Back up existing school records before installing and test the LAN sync, report cards, and printing.

Notifications are drafts only; no live Africa’s Talking API call is made. Provider connection needs an authenticated backend connector.
